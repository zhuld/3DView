# 3DView —— 头动视差 + 手势旋转的 3D 物体查看器

浏览器端的 3D 物体查看器：用普通摄像头识别人头位置与手势，让屏幕变成一扇"看向三维世界的窗口"，
并用拇指与食指捏合拖动旋转模型。无需任何额外硬件，纯前端实现。

- **头动视差**：MediaPipe FaceLandmarker 估计眼位，头部左右 / 上下移动主要带动模型旋转，并辅以轻微的离轴相机位移与前后视差；地面与模型绕同一枢轴同步转动，因此看起来更像视角在移动，而不是模型在原地自转。
- **手势旋转**：MediaPipe HandLandmarker 检测拇指与食指捏合，捏住模型后拖动即可旋转。
- **零运行时代理**：模型与 wasm 在构建时自托管，离线可用，不依赖 CDN。
- **优雅降级**：没有摄像头 / 拒绝授权 / 非安全上下文时，鼠标与触摸仍可完整操作。

## 快速开始

```bash
npm install     # 安装依赖，并自动下载 MediaPipe 模型到 public/
npm run dev     # 打开 http://localhost:5173
```

首次启动会请求摄像头权限（`localhost` 属于安全上下文，可以直接授权）。

## 操作方式

| 交互 | 效果 |
| --- | --- |
| 头部左右移动 | 模型与地面一起绕偏观察者一侧的枢轴偏航摆动，辅以轻微视角横移 |
| 头部上下移动 | 模型与地面一起绕偏观察者一侧的枢轴俯仰摆动，辅以轻微视角纵移 |
| 前后移动 | 视角距离变化，产生深度视差 |
| 拇指与食指捏合后拖动 | 旋转模型（需捏住模型本身） |
| 鼠标左键拖拽 | 旋转模型 |
| 鼠标滚轮 | 调整观看距离 |
| 拖入 `.glb` / `.gltf` / `.obj` 文件 | 载入本地模型（自动居中并归一化尺寸） |
| 「显示」面板中的「显示背景」 | 关闭后画布透明，可叠加到直播 / 录屏软件 |
| 「系统」面板中的主题 | 跟随系统 / 深色 / 浅色，选择保存在本机浏览器 |

面板中的「**重新校准**」会在 0.7 秒内重新记录你的中性头部位置，换人使用或换了坐姿后点一下即可。

> 提示：视差效果的强弱与「视差强度」「观看距离」两个滑杆相关。坐得离屏幕更近、强度调高时，
> 立体感更明显；如果觉得画面晃动，适当降低强度或增强平滑（`HeadPoseEstimator` 中的滤波参数）。

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库（例如 `3DView`），把本项目推送到 `main` 分支：

   ```bash
   git remote add origin https://github.com/<owner>/<repo>.git
   git push -u origin main
   ```

2. 打开仓库 **Settings → Pages → Build and deployment**，将 **Source** 设为 **GitHub Actions**。

3. 推送后 `.github/workflows/deploy.yml` 会自动构建并发布，访问
   `https://<owner>.github.io/<repo>/`。

工作流会以仓库名自动注入 `BASE_PATH`（例如 `/3DView/`），因此不需要改动任何代码；
应用内部所有资源路径都通过 `import.meta.env.BASE_URL` 解析，项目站点子路径下也不会 404。

本地验证 Pages 子路径构建：

```powershell
$env:BASE_PATH = '/3DView/'
npm run build
# 把 dist 放到名为 3DView 的目录下，用任意静态服务器托管后访问 /3DView/
```

CSS 与 JS 使用绝对 base 路径；摄像头需要 **HTTPS** 或 **localhost**，GitHub Pages 默认满足。

## 实现要点

**头动映射**：头部相对校准位置的水平 / 垂直偏移被映射为模型的 yaw / pitch；旋转和手势旋转分别应用在嵌套组上，互不覆盖。相机的横向 / 纵向位移响应降为较弱辅助，深度变化仍用于表现前后移动。

**旋转枢轴**：头动旋转不绕模型自身中心，而是绕"模型中心朝观察者方向前移 `headPivotForward`（默认 1，世界单位）"的一点进行，
即 `T(p)·R·T(-p)`；因此头动时模型会绕靠近观察者的一点摆动，而不是原地自转。该枢轴固定在世界 +z 轴上，
不受拖拽旋转影响，可在控制台用 `__3dview.stage.headPivotForward` 实时调整（设为 0 即恢复绕中心自转）。

**地面同步**：地面（网格 + 阴影承接面）与模型共用同一次头动旋转和同一个世界枢轴，
按 `T(P)·R·T(-P)` 做刚体变换（`viewport.setGroundHeadRotation()`）。二者保持刚体关系，
画面便读作"视角绕着摆动的物体在动"；若地面固定不动，网格不跟随会立刻暴露模型其实是在自转。

**离轴投影**：虚拟屏幕位于 `z = 0`，相机放在估计出的眼位 `E = (ex, ey, D)`，每帧按
`left = near·(-W/2 - ex)/D`、`right = near·(W/2 - ex)/D`（上下同理）重建投影矩阵。
由于视锥始终与 `z = 0` 平面上的屏幕对齐，模型在画面中的位置不变，但相机确实在移动，
模型放在 `z < 0`（屏幕之后），轻微位移会呈现辅助运动视差。

**眼位估计**：取左右眼外眼角（landmark 33 / 263）的中点作为屏幕坐标，按中性位姿归一化；
深度由双眼间距（近大远小）估计，并做限幅。x 轴做镜像处理，符合"摄像头正对人脸"的直觉。
所有信号都经过 1€ filter，兼顾抖动抑制与低延迟。

**捏合判定**：`|拇指尖 - 食指尖| / 掌宽`，小于 0.32 判定捏合、大于 0.48 释放（滞回避免抖动）。
捏合瞬间用食指尖做射线拾取，只有命中模型才进入旋转状态，避免手在画面里随意移动就触发。

## 常见问题

- **没有弹出摄像头授权**：浏览器要求 HTTPS 或 localhost。用局域网 IP 访问时需要 HTTPS。
- **状态条显示 CPU**：GPU delegate 初始化失败，已自动回退；帧率会下降但功能正常。
- **手部识别不灵敏**：保证光线充足、手在画面内且距离适中；也可调高「灵敏度」。
- **视差方向反了**：若你的摄像头是特殊朝向（如倒装），可调整 `headPose.ts` 中 `readEyes()` 的符号。
- **`.gltf` 加载失败**：带外部 `.bin` / 贴图的 glTF 需要与其资源同目录托管，建议先合并为 `.glb`。
- **模型或 wasm 缺失**：重新执行 `npm install`（或 `node scripts/fetch-assets.mjs`）会补齐 `public/models`、`public/wasm`。
- **线上页面空白、看不到模型，本地却正常**：确认 **Settings → Pages → Source** 是 **GitHub Actions**。
  若仍是 **Deploy from a branch**，GitHub 会用 Jekyll 直接发布仓库源码，线上拿到的是未经 Vite 构建的
  `index.html`（其中 `<script src="/src/main.ts">` 无法执行），页面自然是空的；此时工作流里上传的
  `dist/` 产物不会被使用。改回 **GitHub Actions** 后重新运行一次 `Deploy to GitHub Pages` 即可。

## 验收清单

1. 打开页面能看到金属质感的 3D 模型、右上控制面板、左下摄像头预览。
2. 左右 / 上下移动头部，模型与地面一起随头部转动且保留轻微视差；关闭「头动视差」后该响应停止。
3. 拇指食指捏合并拖拽，模型跟手旋转；松开即停止；手在空白处捏合不会误触发。
4. 鼠标拖拽同样可旋转，滚轮可调整观看距离。
5. 拒绝摄像头权限后，页面提示降级信息，鼠标操作仍正常。
6. 拖入 `.glb` 文件后模型被载入并自动居中缩放。
7. 切换语言后界面文案即时更新，刷新后保持。
8. 切换主题（跟随系统 / 深色 / 浅色）立即生效，刷新后保持；关闭「显示背景」后画布透明。
